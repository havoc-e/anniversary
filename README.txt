ANNIVERSARY WEBSITE — QUICK START

1. Open index.html in a text editor.
2. Find the section between:
   EDIT ONLY THIS SECTION
3. Replace the placeholder text inside `content`.
4. For photos, create a folder named `photos` next to index.html and add:
   photo-1.jpg, photo-2.jpg, etc.
5. To change the password, edit:
   password: "YOUR_SECRET"
6. Open index.html in a browser to preview.

To publish it online, upload the folder to any static website host.
No database is required.
